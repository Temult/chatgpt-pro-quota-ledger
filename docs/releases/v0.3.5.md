# v0.3.5: weekly rollover accounting

The on-screen balance now restarts at the same seven-day projected boundary used by the displayed reset date. Previous weeks remain in local history, but no longer reduce the estimate for the new cycle.

This fixes the situation where the next reset advanced by a week while the counter still showed 1/50 remaining. The first projected rollover is based on an earlier server-reported reset; it is not a fresh confirmation that OpenAI restored the allowance.

No changes to automatic detection, profiles, settings, stored events, picker behavior or diagnostics.
