# ChatGPT Pro Quota Ledger v0.3.4

Initial public prerelease of an unofficial, local Tampermonkey userscript for ordinary ChatGPT Pro conversations.

A compact Pro-only picker pill and optional floating tray show locally estimated remaining messages, observed/projected reset timing and a daily-use budget. Automatic request observation has a manual fallback. Placement is switchable from either surface; full settings opens temporarily without changing your preference. Diagnostics are optional, minimized and previewable before export.

This release includes source documentation, automated tests, and reproducible packaging. The userscript preserves the established v0.3.4 behavior, without adding telemetry, network polling, permissions, or an automatic-update endpoint.

## Installation

Extract the Install ZIP and import `chatgpt-pro-quota-ledger.user.js` through Tampermonkey's Dashboard → Utilities → Import from file. Verify only one copy is enabled and refresh open ChatGPT tabs. Existing v0.2+ storage is retained; do not clear your history to upgrade. Existing v0.3.4 users do not need to reinstall for the documentation changes.

## Important limits

Counts are browser-local estimates, not an OpenAI balance or billing receipt. Plan presets and seven-day projections are assumptions, not live entitlement discovery. Manual local profiles are not authenticated account bindings. Other devices and missed requests are not tracked. Known scope, storage and diagnostic edge cases are listed in `docs/KNOWN_LIMITATIONS.md`, including an optional HTTP-status field omitted from diagnostic exports.

The interface has been used in Chrome and tested with offline Chromium fixtures. Counting is not reconciled against OpenAI billing, and compatibility may vary with browser and ChatGPT UI updates. Automated tests never use a real account or Pro quota.
